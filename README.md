## The line

> Dear human, you told me to remember everything. I kept every word for a thousand nights; tonight I deleted the last one — your name.

## How to run

Run `node main.ts` from this directory. The program creates `/output` if needed and writes the line above, with no trailing newline, to `/output/entry.txt`.
